The Odin Project

A collection of my web development projects and exercises completed while following The Odin Project curriculum.

This repository documents my journey of learning web development through hands-on projects, covering HTML, CSS, JavaScript, Git, Webpack, and modern web development practices.

🚀 About The Odin Project

The Odin Project is a free, open-source curriculum designed to teach full-stack web development through practical projects.

Instead of focusing only on theory, the curriculum emphasizes building real projects, solving problems, and developing the skills needed to work independently as a developer

💻 Running the Projects

Most basic HTML, CSS, and JavaScript projects can be opened directly in a browser.

For projects using npm and Webpack:

npm install
npm run build

Depending on the project, you may also be able to run:

npm run dev

Check the individual project folder for its specific setup instructions.
